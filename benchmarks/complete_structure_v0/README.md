# complete_structure_v0

Purpose: exercise ImageProgram's deterministic Construction execution seam on non-blank
incomplete states before introducing learned ranking.

## Phase A0 — Arena Foundation artifact consume

Arena first verifies the cross-repository artifact boundary using the frozen H3c jaw
original-safe/original-rejected pair.

Authority remains ImageProgram's public bundle format `imageprogram-h3c-public-1`. Arena does
not define a compatibility copy of `H3cSummaryV0`; it hash-verifies and preserves the source
`summary.json` object verbatim.

The Foundation gate checks:

- source ImageProgram commit is explicitly pinned
- safe and rejected cells form one jaw/original lineage
- initial state hash is shared
- safe execution is completed, replayable, endpoint-exact and protection-clean
- rejected execution is zero-motor, state-identity and identity-replay
- preparation and continuation costs remain separate
- policy private-data access is zero
- public manifest paths cannot escape into `private/`
- every public file hash matches the ImageProgram manifest

This is an adapter/artifact-boundary claim, not a new H3c semantics claim.

## Phase A — H3c semantics source

ImageProgram H3c itself covers jaw, hair and neck/shoulders across original-safe,
semantic-ID permutation, affine, and protection-conflict cells. Arena does not duplicate that
12-cell falsification matrix.

## Phase B — Construction Ranker v0

A and B receive the exact same candidate set. Freeze candidate generation, candidate budget,
feature contract, Effect Model, protection preflight, Body/Tool/World, lowering, evaluator,
and episode budget.

Report candidate availability, ranking, execution, completion, regret, protection, and
research/execution costs separately. The independent statistical unit is task lineage, not
candidate, stroke, or near-duplicate variant. Evaluator-private oracle execution may diagnose
candidate availability but must not be policy input.
